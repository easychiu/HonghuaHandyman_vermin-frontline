# HonghuaHandyman_vermin-frontline

紅花萬事屋：鼠鼠之亂（Phaser + Vite）。

## 啟動方式

```bash
npm install
npm run dev
```

## 操作方式

### 桌機
- 移動：`WASD` 或 方向鍵左右
- 跳躍 / 爬管：`W` 或 `↑`（在管道旁按住可往上爬）
- 攻擊：`Space`
- 放置陷阱：`E`
- 技能：`1` ~ `5`

### 手機 / 平板
- 左下虛擬搖桿：左右移動，向上推可跳躍 / 爬管
- 右下按鈕：
  - `攻擊`：按住可連續攻擊
  - `陷阱`：放置陷阱
  - `1` ~ `5`：施放技能
- 右上 `觸控UI` 可切換觸控按鍵顯示

## 其他
- 壓力測試加鼠模式：網址加上 `?debugSpawn=1`
